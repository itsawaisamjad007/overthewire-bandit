|                                                                                          |
|                 🎯 OTW TRICK: FINDING THE ONE TRUE PASSWORD FILE                         |
|                ==================================================                        |
|                                                                                          |
|   Agar aapke samne bohot sari directories aur files hain, to system me se sirf           |
|   password wali file nikalne ke liye niche diye gaye rules aur shortcuts use karein:     |
|                                                                                          |
|==========================================================================================|
| RULE 1: THE "FILE TYPE" FILTER (Human-Readable Text Dhoondna)                            |
|==========================================================================================|
|  * Problem: 99% files binary (zeros aur ones), images, ya zero-byte empty files hoti    |
|    hain. Sahi password hamesha ek "ASCII text" (human-readable) file me hota hai.        |
|                                                                                          |
|  * Master Command:                                                                       |
|    --> file inhere/*                                                                     |
|    (Is se folder ki har file ki type show ho jayegi. Aapko output me sirf wo file        |
|    dekhni hai jiske aage "ASCII text" likha ho, baqi sab binary/data ko ignore karein)   |
|                                                                                          |
|==========================================================================================|
| RULE 2: THE "RECURSIVE FIND" SHORTCUT (Nested Folders ko Bypass Karna)                   |
|==========================================================================================|
|  * Problem: Sahi file kisi "maybehere03/file12" ke andar chupi hui hai. Har directory    |
|    me manually ghusna (cd karna) bewaqufi hai.                                           |
|                                                                                          |
|  * Master Command (Find + File Combo):                                                   |
|    --> find . -type f -exec file {} + | grep "ASCII text"                                |
|                                                                                          |
|    * Explanation:                                                                        |
|      - 'find .' --> Current folder aur uske andar ke tamam sub-folders me dhoondo.       |
|      - '-type f' --> Sirf files dhoondo (folders ko chhor do).                           |
|      - '-exec file {} +' --> Mili hui har file par 'file' command chalao.                |
|      - '| grep "ASCII text"' --> Output me se sirf wo line dikhao jo readable text hai.  |
|                                                                                          |
|==========================================================================================|
| RULE 3: THE "GREP EVERYTHING" TRICK (Direct Content Filter)                             |
|==========================================================================================|
|  * Problem: Aapko pata hai ke password file ke andar "bandit" ya koi specific pattern    |
|    likha hoga, ya phir aap har file ka readable content direct screen par lana chahte hain. |
|                                                                                          |
|  * Master Command:                                                                       |
|    --> grep -r "password" . 2>/dev/null                                                  |
|    (Pure system ya folder me jahan bhi 'password' word likha hoga, ye exact file name    |
|    aur text line nikal kar screen par de dega. '-r' ka matlab hai recursive search)       |
|                                                                                          |
|  * Master Command (Human-readable only):                                                 |
|    --> grep -rI "" . 2>/dev/null                                                         |
|    (Isme '-I' capital i hai, jo binary files ko ignore karta hai aur pure folder me      |
|    jitni bhi readable text files hain, unka content show kar deta hai)                   |
